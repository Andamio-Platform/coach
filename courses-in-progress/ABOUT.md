# Courses in Progress

This directory holds course content while you're building it. Each course gets its own subdirectory created by the `course-workflow` skill.

```
courses-in-progress/
└── my-course/
    ├── 00-course.md
    ├── 01-slts.md
    ├── 02-slts-quality-review.md
    ├── 03-lesson-type-classification.md
    ├── 04-readiness-assessment.md
    ├── 05-delegation-map.md
    ├── lessons/
    └── assets/
```

Course content in this directory is gitignored. If you're using the multi-repo pattern, course content lives in a separate repository. See `docs/setup-course-repo.md`.
