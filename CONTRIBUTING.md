# Contributing

Thanks for your interest in improving coach.

## How to Contribute

1. **Open an issue first** — describe what you want to change and why
2. **Fork the repo** and create a feature branch
3. **Make your changes** — follow existing patterns in the skill definitions
4. **Submit a pull request** referencing the issue

## What We're Looking For

- **Skill improvements** — better prompts, clearer instructions, edge case handling
- **Knowledge patterns** — verb banks, quality issues, lesson type heuristics from your own course development
- **New lesson type skills** — authoring skills for specific lesson types (Product Demo, Developer Documentation, etc.)
- **Platform adaptations** — if you've adapted coach for a different platform, share your compile/CLI skills
- **Documentation** — clearer explanations, better examples, corrections

## Guidelines

- Keep skills focused and self-contained
- Test skills by running them against real course content before submitting
- Knowledge contributions should include the source course context
- Follow the existing YAML structure in `knowledge/` files
